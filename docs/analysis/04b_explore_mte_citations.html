Exploration of project citations

Author

Romain Frelat

Published

August 12, 2026

The objective is to explore the associations among FRB-MTE-OFB projects based on shared references.

Based on references, we:

  • quantify the overlap among projects
  • cluster projects based on shared references
  • identify papers that link multiple projects (hubs)

This document is mostly an exploration of how network analysis methodology.

The raw data is not available on Github to safeguard privacy.

Bipartite network

We can build a bi-partite network with references connecting projects.

Code 
netBI <- graph_from_data_frame(
  ref[, c("DOI", "Project")]
)
V(netBI)$type <- V(netBI)$name %in% ref$Project
# V(netBI)$size <- 1
modBI <- cluster_walktrap(netBI)

The bipartite network has 1061 nodes, 1159 edges, a connectance of 0.001 and a modularity of 0.88.

Code 
V(netBI)$color <- ifelse(V(netBI)$type, "red", "blue")

# plot(netBI, layout = layout_as_bipartite(netBI))
visNetwork::visIgraph(netBI)

To analyse the bipartite network, it is best to split it into two networks: - a project network to explore the links among projects - a reference network to explore the centrality of references

Code 
splitBI <- bipartite_projection(netBI)
netREF <- splitBI$proj1
netPR <- splitBI$proj2

Centrality

There are a lot of different measures of centrality. Here we use betweenness (number of shortest paths going through a vertex) and the Google page rank.

Code 
centR <- data.frame(
  "betweenness" = betweenness(netREF),
  "degree" = degree(netREF),
  "pagerank" = page_rank(netREF)$vector,
  "lab" = V(netREF)$title
)

plot_ly(centR) |>
  add_markers(
    x = ~betweenness,
    y = ~pagerank,
    size = ~degree,
    text = ~lab,
    hoverinfo = "text"
  ) |>
  layout(title = "Researcher centrality") |>
  config(
    modeBarButtons = list(list("toImage")),
    displaylogo = FALSE
  )
Code 
info <- apply(centR[, -4], 2, round, 3)
