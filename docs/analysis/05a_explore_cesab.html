Exploration of CESAB groups

Author

Romain Frelat

Published

August 14, 2026

The objective is this document is to explore the diversity and interconnectedness of FRB CESAB projects using network analysis. The exploration consists of two complementary analysis:

  1. project membership network (Section 1)
  2. citation coupling network (Section 2)

2. Citation coupling

We estimate the distance among papers produced by the projects by using the bibliographic coupling, i.e. the pairwize overlap in the reference lists. Documents that share many references are likely working on similar topics or using similar methods.

Coupling network

M <- readRDS(file.path(out_data, "cesab_bibliometrix.rds"))

conv <- data.frame(
  "ori" = sort(unique(M$SO))
)
conv$abb <- sapply(firstup(conv$ori), abbrevr::AbbrevTitle, USE.NAMES = FALSE)

# conv <- conv[!duplicated(conv), ]
mconv <- match(tolower(M$SO), tolower(conv$ori))

M$shortjournal <- conv$abb[match(M$SO, conv$ori)]
M$shorttitle <- substr(firstup(M$display_name), 1, 30)
# get the co-citation network of references
NetMatrix <- bibliometrix::biblioNetwork(
  M,
  analysis = "coupling",
  network = "references",
  n = NULL,
  short = FALSE,
  sep = ";"
)
# dim(NetMatrix) # 395
# table(M$SR %in% dimnames(NetMatrix)[[1]])

# 46722 references with 627 original references

net1 <- igraph::graph_from_adjacency_matrix(
  NetMatrix,
  mode = "undirected",
  diag = FALSE,
  weighted = TRUE
)
V(net1)$name <- M$shortname[match(V(net1)$name, M$SR)]

mod1 <- cluster_fast_greedy(net1)


# delete non connected literature
# net2 <- delete_vertices(net1, degree(net1) == 0)
net2 <- delete_vertices(net1, components(net1)$membership != 1)

# modularity
mod2 <- cluster_fast_greedy(net2)
clu2 <- membership(mod2)
sclu2 <- ifelse(clu2 <= (sum(table(clu2) > 1)), clu2, "isolated")
sclu2 <- as.factor(sclu2)
cclu <- colorspace::qualitative_hcl(n = nlevels(sclu2), palette = "Dark 3")
cclu[levels(sclu2) == "isolated"] <- "#808080" # grey
col2 <- cclu[sclu2]

deg2 <- degree(net2)

The network has 395 nodes (one node = one article), and 11,977 edges (one edge = shared references between two articles). The connectance is 0.046 and the modularity 0.53

For visual representation, we only keep the largest connected community of articles (we removed the disconnected articles).
